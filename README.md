# Spare Parts Automation

## Overview

A Python project for automating spare parts data processing and listing management.

The project is designed to reduce repetitive manual work involved in processing supplier price lists and preparing data for online listings.

## Features

- Processing supplier price lists in Excel format
- Extracting price data from different sources
- Generating XML data for listings
- Downloading price lists from email
- Uploading generated files to Yandex Disk

## Technologies

- Python
- pandas
- Excel file processing
- XML processing
- Email automation
- Yandex Disk integration
